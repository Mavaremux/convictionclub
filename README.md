# Conviction — landing de coaching

## Dirección estratégica
La nueva landing evita el look de "gimnasio genérico" y posiciona Conviction como un club/movimiento de transformación personal. La estética combina:

- status mediante composición editorial y sobriedad, no ornamentos de lujo;
- minimalismo en blanco hueso + negro carbón;
- gym como evidencia visual de disciplina;
- estoicismo mediante lenguaje de estándar, carácter, consistencia y control;
- energía juvenil a través de escala tipográfica, ritmo, microcopy y transiciones.

## Objetivo de conversión
CTA principal: **Aplicar al coaching**.
CTA secundario: **Conoce el método**.

La arquitectura conduce desde identidad → filosofía → oferta → método → filtro de prospecto → aplicación.

## Contenido público tomado como referencia
La presencia pública de Conviction comunica un movimiento juvenil que conecta disciplina física, fortaleza mental, bienestar y estilo de vida. También presenta servicios de trabajo mental, nutrición/entrenamiento y una opción integral. Esta landing reorganiza ese mensaje en una propuesta más premium y orientada a conversión.

## Archivos
- `index.html`: estructura completa.
- `styles.css`: sistema visual, responsive y animaciones.
- `script.js`: menú móvil, reveal on scroll y envío del formulario directamente a WhatsApp.
- `assets/`: fotografías suministradas por el cliente.

## Cómo probar
Abre `index.html` directamente o levanta un servidor estático. Ejemplo:

```bash
python -m http.server 8080
```
